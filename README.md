# 仓序食时 (CangXu ShiShi)

一款面向学生和独居青年的个人记账、库存管理与饮食营养记录工具。

## 功能

- **记账**：采购支出记录，支持多商品明细、多货币、多支付方式
- **库存**：食材库存管理，临期提醒，自动入库/出库，变动日志
- **饮食**：三餐营养记录，每百克/每份模式自动换算，热量 kcal/kJ 切换
- **商品档案**：自动记录商品价格和营养信息，快速录入
- **字典管理**：自定义购买渠道、支付方式、存放位置、分类
- **回收站**：误删数据可恢复
- **云端同步**：支持 Supabase 跨设备同步（可选）
- **香港本地化**：惠康/百佳/佳宝等渠道，八达通/PayMe/FPS 支付，磅/司马斤/两单位

## 使用

直接访问 [GitHub Pages 网址](https://你的用户名.github.io/cangxu-shishi/) 即可使用。

本地使用：下载后用浏览器打开 `index.html`。

## 技术

纯前端实现：HTML + CSS + JavaScript（SPA 单页应用），数据存储使用浏览器 localStorage 或 Supabase 云端数据库。
